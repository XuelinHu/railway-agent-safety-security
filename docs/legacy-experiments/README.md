# Legacy experiment protocols

This directory preserves protocol and hardware-gate records from experiments
that predate the active ADE/CoNLL04 manuscript. They remain here because audit
utilities still reference them, but they are not evidence used by the current
paper.

- `EXPERIMENT_PLAN.md`, `PROTOCOL_FREEZE.md`, and
  `PROTOCOL_V2_AMENDMENT.md`: superseded planning and protocol records.
- `D100_EXECUTION_GATE.md` and `D100_V2_EXECUTION_GATE.md`: generated hardware
  gate reports.
- `PUBLIC_FULL_RUN_PLAN.md`: historical promotion policy still consumed by the
  corresponding audit script.

Current manuscript sources, results, and submission checks live under
[`../../paper/`](../../paper/README.md).
